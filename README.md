# Цель 226

Российский политический тест по мотивам [Objetivo 176](https://objetivo176.es/test?lang=en): 98 вопросов, 14 тем, 9 партий, 450 мест и большинство от 226.

Тест строит условный состав Думы, позволяет собрать коалицию и посмотреть законодательный сценарий России к 2031 году. В сценарии 27 инициатив, поправки, голоса фракций, ограниченные ресурсы и постепенные последствия принятых решений.

Расчёты, анимации и экспорт изображения работают в браузере. Ответы остаются в памяти страницы; обновление сбрасывает прохождение. Сервер и установка зависимостей не требуются.

## Локальный запуск

```sh
npm run serve
```

Откройте `http://127.0.0.1:8789`. Также можно открыть `dist/index.html` напрямую.

## Проверки

```sh
npm test
```

Проверяются расчёт мест, законодательная динамика и прохождение интерфейса в DOM-модели. Это не заменяет визуальную проверку в браузере и на телефоне.

## Публикация

GitHub Actions запускает проверки и публикует содержимое `dist/` на GitHub Pages при обновлении ветки `main`. Пути к ресурсам относительные, поэтому сайт работает и по адресу проекта в подкаталоге.

## Файлы

- `dist/data.js` — вопросы, цена выбора, источники и предварительные оценки партий.
- `dist/model.js` — сравнение ответов, распределение мест и коалиции.
- `dist/bills.js` и `dist/law-sim.js` — инициативы и законодательная динамика.
- `dist/scenario.js` — интерактив коалиции и России 2026–2031.
- `dist/app.js`, `dist/styles.css`, `dist/index.html` — интерфейс.

Численные позиции партий — авторские интерпретации открытых программ; неизвестные оценки обозначены отдельно. Сценарные индексы служат для сравнения решений и не являются прогнозом реальных показателей. Методика и источники доступны внутри сайта.
